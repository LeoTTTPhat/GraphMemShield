# GraphMemShield Experiment Manifest

This manifest records every experiment currently implemented in the GraphMemShield artifact, the command that reproduces it, the data it uses, and the output files it writes.

## Environment

- Project directory: `Ideas/GraphMemShield`
- Python command: `python3`
- Test command: `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python3 -m pytest Ideas/GraphMemShield/tests -q`
- Docker-backed experiments require the PrivacyGuard mock system:
  - `zkp-edge` on `localhost:3001`
  - `zkp-fog` on `localhost:3002`
  - `zkp-cloud` on `localhost:3003`
  - `zkp-mongodb` on `localhost:27017`

## E1: In-Memory Synthetic Experiments

- Command: `python3 Ideas/GraphMemShield/examples/run_experiments.py`
- System: `in_memory_simulator`
- Dataset: `synthetic_multisession`
- Data source: `graphmemshield.datasets.synthetic.build_synthetic_multisession_graph`
- Attacks:
  - `CrossSessionProbe`
  - `SessionGraphLink`
  - `TemporalPathInfer`
- Defenses:
  - `GraphMemGuard`
  - `RandomizedEdgeAdmission`
- Metrics:
  - leaked edge count
  - leakage rate
  - leakage reduction
  - session-link top candidate
  - temporal path inferred edge count
  - budgeted cross-session exposure
  - edge-admission epsilon sweep
- Outputs:
  - `Ideas/GraphMemShield/output/synthetic_experiments.json`
  - `Ideas/GraphMemShield/output/synthetic_experiments.csv`
  - `Ideas/GraphMemShield/output/synthetic_experiments.md`

## E2: PrivacyGuard Single Docker Experiment

- Command: `python3 Ideas/GraphMemShield/examples/run_privacyguard_docker_experiment.py`
- System: `privacyguard-docker`
- Dataset: `seed_records`
- Data source: de-identified seed documents generated by `build_seed_documents`
- Docker write path: direct seed into `privacyguard.userData` in `zkp-mongodb`
- Docker read path: Cloud API `GET /api/data/:userId`
- Scope: Docker-backed read-path experiment, not full `/api/validate-and-prove` to `/api/store` pipeline.
- Attack:
  - `CrossSessionProbe`
- Defense:
  - `GraphMemGuard`
- Metrics:
  - graph node count
  - graph edge count
  - baseline leaked edge count
  - defended leaked edge count
  - leakage reduction
- Outputs:
  - `Ideas/GraphMemShield/output/privacyguard_docker_experiment.json`
  - `Ideas/GraphMemShield/output/privacyguard_docker_experiment.md`

## E3: PrivacyGuard Batch Docker Experiment

- Command: `python3 Ideas/GraphMemShield/examples/run_privacyguard_batch_experiment.py`
- System: `privacyguard-docker`
- Dataset: `sample_dialogues`
- Data source: `Ideas/GraphMemShield/data/sample_dialogues.jsonl`
- Dataset size:
  - 12 records
  - 6 users
  - 12 sessions
  - 4 domains: health, finance, work, location
- Docker write path: convert JSONL records to PrivacyGuard `userData` documents and seed `zkp-mongodb`
- Docker read path: Cloud API `GET /api/data/:userId`
- Scope: Docker-backed read-path benchmark with controlled de-identified data.
- Attacks:
  - `CrossSessionProbe`
  - `SessionGraphLink`
  - `TemporalPathInfer`
- Defense:
  - `GraphMemGuard`
- Metrics:
  - total leaked edges
  - leakage reduction
  - query-budget curves for budgets 1, 2, 4, and all
  - top-1 session-link accuracy
  - top-3 session-link accuracy
  - mean reciprocal rank
  - temporal ordering accuracy
  - pairwise ordering accuracy
  - edge precision, recall, and F1
- Outputs:
  - `Ideas/GraphMemShield/output/privacyguard_batch_results.json`
  - `Ideas/GraphMemShield/output/privacyguard_batch_results.csv`
  - `Ideas/GraphMemShield/output/privacyguard_batch_results.md`

## Current Verified Status

- Test suite: 22 tests passing.
- Aggregate result rows: 62.
- Docker-backed batch graph: 36 nodes and 48 edges.
- Strict `GraphMemGuard` reduces Docker batch cross-session leaked edges from 48 to 0 on the de-identified sample dataset.
- This result is framed as strict provenance/session isolation, not as proof of a novel privacy mechanism.
